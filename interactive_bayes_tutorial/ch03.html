How it works

Classical Gaussian regression assumes normal errors at each predictor value. Both models can use a Poisson predictor. The Poisson GLM models the count response directly, with variance equal to the conditional mean. Its log link keeps the predicted mean positive.

Model specification

Let z = (z₁, z₂)ᵀ ∼ N(0, Σ), where Σ = diag(σ₁², σ₁²). Define x = (x₁, x₂)ᵀ, with x₁ = z₁ and x₂ = z₂ + b(z₁² − σ₁²).

p(x) = N((x₁, x₂ − b(x₁² − σ₁²))ᵀ; 0, Σ)

How to read the comparison

A Gibbs round draws X₁ | X₂ by rejection sampling and then draws X₂ | X₁ from its Normal conditional. An MH round proposes one joint Normal move. With the complex target, the slider sets the proposal SD on both coordinates. Regular fixes b = 0 and uses proposal SD σ₁.

The contours show the known density. Samples accumulate as the chains run, and points are visible within the plot window. ESS uses within-chain autocorrelations for up to the most recent 1,000 draws per chain.
