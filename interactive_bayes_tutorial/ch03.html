Test RMSE measures prediction error against the observed counts, in counts. Lower is better.

How it works

Classical Gaussian regression assumes normal errors at each predictor value. Both models can use a Poisson predictor. The Poisson GLM models the count response directly, with variance equal to the conditional mean. Its log link keeps the predicted mean positive.

How to read the comparison

A Gibbs round draws X₁ | X₂ by rejection sampling and then draws X₂ | X₁ from its Normal conditional. An MH round proposes one joint Normal move. With the complex target, the slider sets the proposal SD on both coordinates. Regular fixes b = 0 and uses proposal SD σ₁.

The contours show the known density. Samples accumulate as the chains run, and points are visible within the plot window. ESS uses within-chain autocorrelations for up to the most recent 1,000 draws per chain.

Each point averages over the same 40 held-out predictor values. RMSE compares the five predicted means with the five true means.

How partial pooling works

The GLM uses one intercept for all groups. The GLMM estimates a separate intercept for each group and pulls it toward the shared intercept, typically more strongly when a group has less information. The sliders set the true parameters used to generate the data. The fits estimate their parameters from the training counts.

The figures use approximate posterior predictive means. A Laplace approximation fits the coefficients, and numerical quadrature averages the GLMM predictions over the posterior of τ. Laplace approximation reference
